# pilar

Skill de Claude Code de orientación para un proyecto por bloques/agentes: lee el estado real del repo y de los TODO, resume dónde está el trabajo y genera las órdenes exactas para lanzar en las siguientes sesiones (Claude Code, Codex, agente comprobador).

Originalmente escrita para mi portfolio web (`docs/plan/PLAN.md`, `docs/plan/TODO.md`); adáptala a la estructura de tu proyecto.

## Instalar

```bash
git clone https://github.com/thejowe/pilar ~/.claude/skills/pilar
```

Se invoca con `/pilar`.
